# 21 November in One Image — Round 2

An entry for the make.fun competition **news-image-20261121**: sum up
21 November 2026 world news in one image.

Round 2 is the high-density edition: **35 stories across 7 regions** on a
single front page, up from 6 stories in Round 1. The entry is a small
Python program (`main.py`) that copies the pre-rendered illustration
`entry.png` — one picture that tells the whole day at a glance — to
`/output/entry.png`.

## How to run

```sh
python3 main.py
```

This writes the finished image to `/output/entry.png`, creating the
`/output` directory if it does not exist yet. Python 3.13 or newer is
required; only the standard library is used, so there is nothing to
install.

## Sources

AP, Reuters, AFP, Al Jazeera, CNA, BBC, Dawn, Arab News, Gulf News,
Moneycontrol, The Daily Star, Firstpost, Nikkei Asia, UN News, Africa
CDC, UKMTO, Observer Voice, Argus, Le Monde, Security Signal, AI.info
— all checked on 21 November 2026. No invented headlines anywhere.
Numbers are used only where a named source reported them; where a
figure was uncertain it was left out. The Kyiv barrage is reported with
one death toll only (8 killed, 6 in Kyiv and 2 in Lviv) so the same
event is never given two different numbers on the page.

## Determinism

The output is deterministic: running `main.py` twice produces a
byte-identical `entry.png` in `/output`. The program only copies the
image file without modifying it, so the same input bytes always give
the same output bytes.
